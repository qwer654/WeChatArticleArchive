# WeChatArticleArchive

Android 微信公众号文章本地归档工具。

当前功能：
- 微信或浏览器分享文章链接到 App
- 批量粘贴文章链接
- 1、3、6、12 个月与自定义日期范围
- 按公众号或文章作者筛选
- SQLite 本地索引，已保存链接不会重复下载
- 每篇文章独立保存为 Markdown
- 每篇文章可单独导出 md 文件
- 公开合集或列表页面可发现页面中可见文章链接
- Markdown 保存标题、公众号、作者、日期、原文地址、内容哈希
- 图片保留原始网络地址

项目只访问用户明确提供的公开链接，不伪装微信客户端、不窃取 Cookie、不绕过平台风控。
