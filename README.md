# WeChatArticleArchive

Android 微信公众号文章本地归档工具。

当前功能：
- 微信或浏览器分享文章链接到 App
- 批量粘贴文章链接
- 1、3、6、12 个月与自定义日期范围
- 按公众号或文章作者筛选
- SQLite 本地索引，已保存链接不会重复下载
- 每篇文章独立保存为 Markdown
- 每篇文章可单独导出 md 文件
- 公开合集或列表页面可发现页面中可见文章链接
- Markdown 保存标题、公众号、作者、日期、原文地址、内容哈希
- 图片保留原始网络地址

项目只访问用户明确提供的公开链接，不伪装微信客户端、不窃取 Cookie、不绕过平台风控。


可选历史同步模式：
- 使用微信读书二维码登录兼容服务。
- 从一篇样例公众号文章识别公众号。
- 按页读取历史文章索引，再按选择日期范围下载正文。
- 本地已有 URL 直接跳过，连续命中已有文章时提前结束，避免每次重抓全部正文。
- 登录令牌只保存在手机本地，不写入日志或 Markdown。
- 遇到 401/429 立即停止并提示，不尝试规避平台限制。
- 当前兼容服务基于 WeWe RSS 使用的 weread.111965.xyz；这是第三方服务，可不启用。


## 版本与签名

- 当前应用内会显示软件版本、versionCode 和仓库地址。
- 从 v0.1.4 起 Debug APK 使用固定的 Stable Dev 开发更新签名，后续同一 applicationId 的测试版可直接覆盖升级。
- v0.1.3 及更早版本由 GitHub Actions 临时 Debug Key 签名，因此升级到 v0.1.4 时需要卸载旧版一次。
- Stable Dev 签名仅用于开发/测试，不作为正式商店发布签名。
